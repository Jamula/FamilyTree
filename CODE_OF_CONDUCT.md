# FamilyTree Community Code of Conduct

We welcome respectful collaboration across backgrounds, generations, cultures and family structures. Treat other contributors with dignity.

## Expectations
- Be considerate and constructive in code reviews, issues and discussions.
- Respect differing family structures and naming or cultural practices.
- Avoid harassment, threats, discrimination, personal attacks, doxxing and unwanted personal contact.
- Never post real genealogy records, private photographs, secrets, contact information or information about living relatives into public GitHub.

## Moderation
Maintainers may edit, hide, lock or remove abusive content, restrict participation, or report serious threats to the platform. Decisions should be proportional, documented where safe, and open to private appeal.

For ordinary conduct concerns, contact a repository maintainer privately through GitHub, sharing only the minimum necessary facts. **Do not use public issues to report vulnerable-person data or security flaws.** For security vulnerabilities, use the private form described in [SECURITY.md](SECURITY.md).

## Scope
This policy applies to public project collaboration, reviews, online events and spaces represented as official FamilyTree channels.
